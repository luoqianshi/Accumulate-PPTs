01 / Background

为什么需要频率感知的上采样？

密集预测（分割 / 检测）中，HR 特征富细节、LR 特征富语义。传统融合方式在频率视角下存在三个系统性缺陷。

问题一 · Aliasing

上采样混叠

低分辨率特征经最近邻 / 双线性直接放大，相当于欠采样信号重建：高频成分折叠回低频，产生边缘锯齿与棋盘伪影，类别边界被污染。

问题二 · Detail Loss

高频细节衰减

骨干网络多次下采样后，小目标与细边界信息已不可逆衰减；常规上采样只做平滑插值，无法主动恢复或增强这些高频成分。

问题三 · Mismatch

双流频率失配

HR 多细节少语义、LR 多语义少细节，二者频率分布天然错位；简单相加或拼接会让高频噪声与低频语义互相干扰。

FreqFusion 的应对：按频率分量分别治理

对 LR 特征施加自适应低通滤波（ALPF）抑制混叠再上采样；对 HR 特征施加自适应高通滤波（AHPF）增强细节；两者掩码均由双流内容动态生成。

02 / Architecture

FreqFusion 整体运算流程

输入为双流特征 (hr_feat, lr_feat)，HR 空间尺寸 = 2× LR 且通道一致；输出为两路滤波结果逐元素相加 [B, C, 2H, 2W]。

注：掩码实际由 c_hr 与 Up(c_lr) 两路共同生成后经核归一化；初始化 std=0.001 使模块初始行为接近恒等映射，Hamming 窗作为正则平滑核权重。

03 / Filter Details

两个关键算子的内部运算

核归一化保证滤波器“低通 / 高通”的数学性质；CARAFE 完成内容感知的加权重组与上采样。

算子一 · kernel_normalizer

核归一化：让掩码成为真正的滤波器

1

reshape：[B, k², 2H, 2W] → [B, 1, k², 2H, 2W]，k² 为核内位置数（5×5=25 / 3×3=9）

2

softmax：在 k² 维上做 softmax，保证核内权重非负、可比较

3

× Hamming 窗：中心强、边缘弱的二维窗，正则化核形状（平滑先验）

4

÷ Σ 归一：每个空间位置的核权重和 = 1，维持特征能量稳定

m̂ = ( softmax(m) ⊙ H ) / Σ( softmax(m) ⊙ H )
算子二 · CARAFE

内容感知重组：k×k 邻域加权求和

每个输出位置的值 = 输入 k×k 邻域与内容预测核的加权和。ALPF 用 5×5 核做 ×2 抗混叠重组；AHPF 用 3×3 核在原分辨率上提取高频分量（hr − HP(hr) 即高通残差）。

04 / Plug & Play

爆改：FreqFusionUpsample 适配器

原版要求双流输入，与 YOLO / Ultralytics 中 nn.Upsample 的单输入接口不兼容 —— 用一个 5 行包装器解决。

输入 / 输出契约

单输入进，×2 特征出，通道不变

输出 [B, C, 2H, 2W]：HP(nearest_up(x)) + ALPF_up(x)。接口与 DySample / nn.Upsample 完全一致，可直接原位替换并保留后续 Concat。

class FreqFusionUpsample(nn.Module): # 即插即用上采样适配器（类 DySample 用法） def __init__(self, channels, **kwargs): super().__init__() self.ff = FreqFusion([channels, channels], **kwargs) def forward(self, x): hr_feat = F.interpolate(x, scale_factor=2, mode='nearest') return self.ff((hr_feat, x))

为什么这样改是安全的

· 合成的 HR 流与官方 head 中 nn.Upsample(scale=2, nearest) 行为一致
· 内部 ALPF / AHPF 运算零改动，kwargs 原样透传
· 上采样不改通道数，预训练权重迁移不受影响
· 初始化 std=0.001，初始行为≈nearest 上采样，训练平稳起步

04 / Plug & Play

原始 FreqFusion vs FreqFusionUpsample

差异只在“HR 流从哪来”：一个接真实高分辨率特征做融合，一个用 nearest 合成 HR 做纯上采样。

维度 原始 FreqFusion FreqFusionUpsample（爆改）
输入双流 (hr_feat [B,C,2H,2W], lr_feat [B,C,H,W])单输入 x [B,C,H,W]
HR 流来源骨干 / 解码器的真实高分辨率特征nearest 2× 上采样合成（与官方 head 一致）

05 / Comparison

对照组：DySample 的运算原理

DySample（ICCV 2023）走的是另一条路：不预测滤波核，而是预测“去原特征图的哪个位置取点”。

点采样范式 · Point Sampling

偏移生成 + 双线性重采样

机制特征

轻量，但没有显式频率建模

· 单输入单输出：[B,C,H,W] → [B,C,2H,2W]，接口与 nn.Upsample 一致

· 点采样：学习“去哪里取点”（offsets），而非“用什么核滤波”（kernels）

· 极轻量：仅 1 个 1×1 卷积（+ 可选 scope 调制），几乎零额外开销

· 分组共享：groups=4 组通道共享同一组采样坐标

· 平稳初始化：std=0.001，初始 offset ≈ init_pos，等价最近邻网格

一句话对比

DySample 是“重新摆放采样点”；FreqFusion 是“按频率分量设计滤波器再重组”。前者隐式、轻量；后者显式、可解释、对混叠与细节分别治理。

01

FreqFusion 的本质

ALPF（5×5 低通）对 LR 抗混叠 ×2 上采样 + AHPF（3×3 高通）对 HR 细节增强，输出两路逐元素相加 [B,C,2H,2W]。

02

爆改版只做一件事

用 nearest 2× 合成 HR 流，把双流融合器包装成单输入单输出的 FreqFusionUpsample，可直接替换 nn.Upsample，通道不变、预训练可迁移。

03

与 DySample 的根本差异

滤波重组 vs 点采样；显式频率建模 vs 隐式偏移学习。精度取向选 FreqFusion，极致轻量选 DySample。
