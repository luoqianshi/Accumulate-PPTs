Paper Reading · 上采样 ICCV 2023

DySample:
Learning to Upsample
by Learning to Sample

超轻量且有效的动态上采样器 —— 绕开动态卷积，从点采样（point sampling）的视角重新形式化上采样

Wenze Liu · Hao Lu · Hongtao Fu · Zhiguo Cao 华中科技大学人工智能与自动化学院
ICCV 2023 CCF-A 论文代码 github.com/tiny-smart/dysample
Overview · Contributions

核心贡献

01

点采样视角重形式化

绕开动态卷积，把上采样重新形式化为点采样：为每个上采样点生成内容感知的采样偏移，再用 PyTorch 内置的 grid sample 函数对连续特征图重采样

02

绕开动态卷积 · 超轻量

无需耗时的动态卷积与定制 CUDA 实现，所需参数量、FLOPs、GPU 显存与延迟大幅低于 CARAFE、FADE、SAPA 等先前方法

03

朴素实现 + 逐步改进

先给出朴素实现，再经控制初始采样位置、约束偏移移动范围、按通道分组三个逐步改进强化上采样行为，最终组合出四个变体

04

五任务全面领先

在语义分割、目标检测、实例分割、全景分割、单目深度估计五个密集预测任务上均优于已有上采样器

Motivation · 1/2

研究动机：上采样地位与插值算子的不足

特征上采样（Feature Upsampling）是密集预测模型中逐步恢复特征分辨率的关键环节，其质量直接决定逐像素预测的精度——编码器-解码器结构普遍要面对「低分辨率特征如何高质量放大」的问题

NN / 双线性

固定规则 · 忽略语义

最常用的最近邻插值与双线性插值按固定规则取值，完全忽略特征图中的语义信息

反卷积

棋盘伪影

为增加灵活性引入的可学习上采样器，但存在棋盘伪影问题

Pixel Shuffle

高层任务不友好

另一类可学习上采样器，但对高层任务并不友好

Motivation · 2/2

核范式动态上采样器的代价

  • CARAFE：用子网络生成内容感知的动态卷积核来重组特征；FADE / SAPA 又把高分辨率引导特征与低分辨率输入一起送入核生成过程
  • 核范式方法结构复杂，依赖耗时的动态卷积、需定制 CUDA 实现，推理开销远高于双线性插值
  • FADE / SAPA 依赖高分辨率引导特征：额外计算量、缩小适用场景；且 FPN 中高分辨率特征本来就会在上采样后与低分辨率特征相加融合，上采样器单独摄入高分辨率特征的必要性存疑
  • 问题收窄：仅需低分辨率单输入 + 接近插值算子的开销 + 动态上采样器的精度，此前暂无工作同时做到
DySample 与其它上采样器的精度-延迟对比：五个任务均优于已有上采样器，参数量、FLOPs、显存与延迟大幅低于 CARAFE、FADE、SAPA
Method · Point Sampling View

从点采样视角看上采样

  • 上采样本质上是对几何信息的建模，本文把它回归为本源——点采样（point sampling）
  • 给定大小为 C × H1 × W1 的特征图 X 与大小为 2 × H2 × W2 的采样集 S（第一维的 2 表示 x 与 y 坐标）
  • grid sample 函数用 S 中的位置，对假想的双线性插值后连续特征图重采样，得到 C × H2 × W2 的 X′
核心定义

X′ = grid sample(X, S)

X：低分辨率输入特征 · S：采样位置集合 · X′：重采样得到的高分辨率特征

直观上，只要采样位置取得足够「懂内容」，无需动态卷积也能完成内容感知的上采样

Method · Naive Implementation

朴素实现：线性层逐点生成偏移

  • 给定上采样倍率 s 与特征图 X，用一个输入输出通道数为 C → 2s² 的线性层生成偏移
  • 偏移经 Pixel Shuffle 重排为 2 × sH × sW
  • G 为标准的规则采样网格，O 为逐点生成的偏移
偏移与采样集

O = linear(X)  ·  S = G + O

初步成绩：Faster R-CNN 37.9 AP、SegFormer-B1 41.9 mIoU，与 CARAFE（38.6 AP、42.8 mIoU）尚有差距——朴素的偏移生成还不足以支撑高质量上采样

朴素实现的采样式动态上采样数据流：采样点生成器产出采样集后，grid sample 直接输出上采样特征
Method · Improvement ①

改进 ①：初始采样位置 nearest → bilinear

  • 问题：朴素实现中 s² 个上采样点共享同一个初始位置（X 中的标准网格点），位置关系被忽略、初始分布不均
  • 若生成的偏移全为零，结果等价于最近邻插值，故称「nearest 初始化」
  • 改进：bilinear 初始化——s² 个采样点的初始位置按双线性插值方式均匀分布，零偏移恰好还原双线性插值
  • 更换初始化后：38.1（+0.2）AP、42.1（+0.2）mIoU
  • 这一步只改动初始化方式，未引入任何参数；输出的偏移将送入范围约束环节
nearest 初始化、bilinear 初始化与偏移范围约束的对比：零参数改动即 +0.2 AP / +0.2 mIoU
Method · Improvement ②

改进 ②：偏移重叠与静态范围因子

  • 问题：归一化层使输出特征取值落在以 0 为中心的 [-1, 1]，局部 s² 个采样点的走动范围显著重叠 → 边界附近的点值混乱，误差逐级传播形成语义伪影
  • 缓解：给偏移乘上 0.25 系数——恰好满足重叠与不重叠之间的理论边界条件，称为「static scope factor」，把走动范围局部约束在相邻网格单元内
  • 设置后：38.3（+0.2）AP、42.4（+0.3）mIoU
  • 乘法是软约束，无法彻底消除重叠；用 tanh 硬约束到 [-0.25, 0.25] 反而更差——显式约束限制了表达能力（某些位置需要大于 0.25 的偏移时无法处理）
偏移重叠引发边界混乱与语义伪影
Static Scope Factor

O = 0.25 · linear(X)

Method · Improvement ③

改进 ③：特征分组

  • 目标：让不同通道子空间各自拥有独立的采样集——沿通道维把特征图分成 g 组，每组生成一份偏移
  • LP 与 PL 两种风格下，增大分组数都能持续涨点
  • 当 g = 4 时：38.6（+0.3）AP、43.2（+0.8）mIoU
  • 三步改动中收益最大的一步
  • 分组后，每个通道组内的偏移生成还要面对「先线性还是先重排」的选择 → 引出偏移生成风格设计
特征分组数的消融曲线：LP 与 PL 两种风格下增大分组数均持续涨点，g = 4 时达 38.6 AP / 43.2 mIoU
Method · Improvement ④

改进 ④：动态范围因子

  • 动机：静态因子全局固定、灵活性有限，为进一步放开偏移的尺度，用线性投影逐点生成「dynamic scope factor」
  • 通过 sigmoid 函数与 0.5 的系数，动态范围取值落在 [0, 0.5]、以 0.25 为中心，与静态版本的中心一致
  • linear1 生成逐点的动态范围因子，linear2 生成原始偏移，二者逐元素相乘实现自适应缩放
  • 再把性能推高至 38.7（+0.1）AP、43.3（+0.1）mIoU
  • 静态与动态版本共享「生成偏移、与网格相加得到采样集」的流程
Dynamic Scope Factor

O = 0.5 · sigmoid(linear1(X)) ⊙ linear2(X)

取值范围 [0, 0.5]，以 0.25 为中心

Method · LP / PL & Variants

偏移生成风格与四个变体

  • LP（linear + pixel shuffle）：先用线性投影产出 s² 组偏移、再重排以满足空间尺寸
  • PL（pixel shuffle + linear）：先重排再线性投影，参数量降至 LP 的 1/s⁴，但需额外存储重排后的特征，显存与延迟略高
  • 四个变体：DySample（LP+静态）/ DySample+（LP+动态）/ DySample-S（PL+静态）/ DySample-S+（PL+动态）
  • 分组数按经验取：LP 版本 g = 4、PL 版本 g = 8
  • PL 在 SegFormer 与 MaskFormer 上更好，但在其余测试模型上略差
LP 与 PL 两种偏移生成风格对比
Method · Working Mechanism

工作机制与相关工作的关系

采样过程可视化：边界上的低分辨率点被划分为四个上采样点——左上角划入「天空」、其余三个划入「房子」，边缘更清晰；右子图展示右下角上采样点如何由双线性插值合成
  • vs CARAFE：DySample 生成的是上采样位置而非卷积核——核范式视角下等价于 2 × 2 双线性核，而 CARAFE 至少需 3 × 3 的核尺寸，GFLOPs 至少是 DySample 的 2.25 倍
  • vs SAPA：偏移生成同样可视为为每个点寻找语义相似的区域，但 DySample 不需要引导图，更高效也更容易使用
  • vs 可变形注意力：后者在每个位置采样多个点聚合成新点以增强特征；DySample 面向上采样，每个上采样位置只采 1 个点，把一个点划分为 s² 个点——只要这 s² 个点能被动态划分，单点采样就足够了

Summary · Strengths

优点与创新点

01

点采样重形式化

绕开核范式与定制 CUDA 包，仅凭 PyTorch 内置的 grid sample 函数即可实现内容感知的动态上采样，工程可用性与部署友好度极高

02

轻量特性极为突出

仅以数万级参数增量在五个密集预测任务上全面超越 CARAFE、FADE、SAPA，延迟逼近双线性插值，可安全替换现有密集预测模型中的 NN / bilinear 插值

03

研究范式清晰可复用

「朴素设计 + 逐步改进」：每一步改动（初始化、范围约束、分组、动态因子）都有动机解释与消融数据支撑，实验丰富，值得改进类工作模仿

Discussion · Limitations

局限与批判性讨论

01

边界质量不敌引导类

bIoU（29.12–29.93）全面低于 FADE（31.68）与 SAPA-B（30.96），改善主要在内部区域；对边界敏感的任务（深度抠图、医学影像分割），引导类方法仍有一席之地

02

并非所有任务都有一致收益

深度估计上 DySample+ 仅 +0.05（δ<1.25）与 -0.04（Abs Rel）；DySample-S 的 0.871 反而低于 bilinear 的 0.873——变体选择不当可能无增益

03

变体与超参依赖经验

PL 在 SegFormer / MaskFormer 上更好、其余模型略差；分组数按经验取 LP=4、PL=8，实际使用仍需针对自己的骨干做一轮消融

04

评测范围有限

限于 ×2 上采样与 FPN 类融合结构；更大上采样倍率以及与其它特征融合方式的组合效果在原文中未获取
